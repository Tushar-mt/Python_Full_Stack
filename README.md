# 🎨 SnapFolio — My First Portfolio Website

> A responsive portfolio UI built with HTML & CSS as part of my self-learning journey as an engineering graduate.

---

## 📌 Project Overview

SnapFolio is a modern, multi-device portfolio template designed to showcase a UI/UX designer's work. It features three responsive layouts:
- 🖥️ Desktop view
- 📱 Tablet view
- 📲 Mobile view

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Page structure & semantic markup |
| CSS3 | Styling, layout, animations |
| Flexbox | Responsive alignment |
| Font Awesome | Icons for navigation & social links |

---

## ✨ Key Features

- Dark-themed UI with elegant color palette
- Sidebar navigation with icons + text labels
- Responsive design across 3 device types
- Social media icon integration
- Clean typography hierarchy (H1, H2, H3)
- Styled buttons with rounded borders
